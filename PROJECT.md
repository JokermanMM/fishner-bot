# 🎣 Дневник рыбака — смысл и архитектура проекта

## Зачем этот проект

Это не публичный сервис, а общий рыболовный дневник для компании из 3–4 друзей. Бот должен быть удобен на водоёме: открыл Telegram, добавил фото, вес и остальные поля, получил красивую карточку.

Рабочее имя Telegram-бота: `@fishner_bot`.

Вторая часть идеи — дружеское соревнование: общая лента, таблица рекордов, количество уловов, суммарный вес, виды рыбы и личные достижения каждого участника.

## Правила данных

- Вход только по секретной пригласительной ссылке.
- Уловы и статистика видны всем допущенным друзьям.
- В каждой записи хранится автор.
- Точные координаты доступны всем допущенным друзьям внутри бота.
- Координаты не публикуются в inline-карточках для произвольных Telegram-чатов, где могут быть посторонние.
- Название водоёма можно показывать.
- Фото и видео в MVP хранятся как Telegram `file_id`. Резервное файловое хранилище — следующий этап.

## Как работает бот

1. Друг открывает ссылку `https://t.me/fishner_bot?start=<FRIEND_INVITE_CODE>`.
2. Бот сохраняет участника как допущенного.
3. Кнопка «Добавить улов» запускает пошаговую форму: после фото бот спрашивает, сколько рыб нужно внести — от 1 до 20.
4. Для каждой рыбы отдельно вводятся вид, вес и длина. Фото или видео, место, дата, приманка, судьба рыбы и заметка применяются ко всей сессии.
5. На шаге геолокации рыбак может отправить новую точку или выбрать своё последнее именованное место; во втором случае координаты и название подставляются вместе.
6. Дату можно ввести цифрами (`27.10.2026 09:00`) или словами (`27 октября 2026 г. в 09:00`).
7. Перед записью показывается общий предпросмотр; пакет сохраняется одной транзакцией, но каждая рыба становится самостоятельной записью.
8. После сохранения рыбы попадают в общую ленту, рекорды и статистику.
9. Карточку каждой рыбы можно отправить в любой Telegram-чат через inline-режим.

## Рейтинги

- Общая статистика сравнивает рыбаков по числу уловов, суммарному весу, числу видов и рекордам.
- Кнопка «Статистика» по умолчанию открывает топ отдельных уловов всей компании по весу.
- Топ можно отфильтровать по виду рыбы или по имени рыбака.
- В каждом топе можно переключать сортировку между весом и длиной; записи без длины не участвуют в рейтинге по длине.
- Список видов строится динамически по рыбам, которые уже добавили участники.

## Бесплатная архитектура

```text
Telegram
   │ webhook
   ▼
Render Free Web Service ──────► Neon Free Postgres
   ▲          ▲                       ▲
   │          │ /health every 5 min   │ persistent data
   │      UptimeRobot Free            │
   │ deploy hook                      │
GitHub Actions ◄── GitHub repository
```

- Render запускает HTTP-сервис и принимает webhook Telegram.
- Render собирает TypeScript с явно установленными `devDependencies`, даже при `NODE_ENV=production`, а после сборки удаляет их из runtime-окружения.
- UptimeRobot проверяет `/health` раз в 5 минут и не даёт Render достичь 15 минут без входящего трафика.
- Render всё равно может перезапустить Free-сервис во время обслуживания, поэтому webhook и база рассчитаны на безопасный рестарт.
- Локальный диск Render временный, поэтому база находится в Neon Postgres.
- GitHub Actions проверяет типы, тесты и сборку, затем вызывает секретный Render Deploy Hook.

## Текущий продакшен

- Render Web Service: `https://fishner-bot.onrender.com`.
- Проверка доступности: `https://fishner-bot.onrender.com/health`.
- Первая успешная публикация выполнена 7 октября 2026 года.
- Деплой из GitHub Actions запускается только после успешных проверок через секрет `RENDER_DEPLOY_HOOK_URL`.
- UptimeRobot проверяет `/health` методом `HEAD` каждые 5 минут; endpoint также поддерживает обычный `GET` для ручной диагностики.

## Секреты

Ни одно значение из этого списка не должно попадать в Git:

- `BOT_TOKEN` — токен BotFather;
- `DATABASE_URL` — строка подключения Neon;
- `FRIEND_INVITE_CODE` — код приглашения;
- `WEBHOOK_SECRET` — секрет проверки webhook;
- `RENDER_DEPLOY_HOOK_URL` — секрет GitHub Actions.

## Этапы

### MVP

- приватное вступление;
- добавление улова;
- пакетное добавление нескольких рыб с одного фото или видео;
- общая лента;
- общие рекорды;
- рейтинг друзей и фильтруемые топы уловов;
- публикация карточек в чатах;
- Render + Neon + GitHub Actions + UptimeRobot.

### Следующий этап

- Telegram Mini App с галереей, картой, календарём и графиками;
- резервное копирование медиа;
- именные рыбалки и совместные выезды;
- номинации и шуточные достижения.
