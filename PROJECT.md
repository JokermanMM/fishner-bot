# 🎣 Дневник рыбака — смысл и архитектура проекта

## Зачем этот проект

Это не публичный сервис, а общий рыболовный дневник для компании из 3–4 друзей. Бот должен быть удобен на водоёме: открыл Telegram, добавил фото, вес и остальные поля, получил красивую карточку.

Рабочее имя Telegram-бота: `@fishner_bot`.

Вторая часть идеи — дружеское соревнование: общая лента, таблица рекордов, количество уловов, суммарный вес, виды рыбы и личные достижения каждого участника.

## Правила данных

- Вход только по секретной пригласительной ссылке.
- Уловы и статистика видны всем допущенным друзьям.
- В каждой рыбе хранится настоящий рыбак, а у всего улова отдельно хранится участник, который внёс запись.
- Точные координаты доступны всем допущенным друзьям внутри бота.
- Координаты не публикуются в inline-карточках для произвольных Telegram-чатов, где могут быть посторонние.
- Название водоёма можно показывать.
- Один улов содержит 1–10 фотографий, которые хранятся как Telegram `file_id` один раз на весь улов. Видео не поддерживается. Отдельное резервное файловое хранилище в текущую дорожную карту не входит.
- Вид рыбы задаётся только буквами, пробелами и дефисами. Значения вроде `500 г` или `4,2 кг` не принимаются как вид.
- Все допущенные друзья могут управлять записями общего дневника. Удаление улова, отдельной рыбы или фотографии всегда требует явного подтверждения.

## Как работает бот

1. Друг открывает ссылку `https://t.me/fishner_bot?start=<FRIEND_INVITE_CODE>`.
2. Бот сохраняет участника как допущенного.
3. Кнопка «Добавить улов» запускает пошаговую форму: участник присылает 1–10 фотографий альбомом или по одной, подтверждает завершение и указывает количество рыб — от 1 до 20.
4. Для каждой рыбы отдельно выбирается настоящий рыбак, затем вводятся вид, вес и длина. Рыбака можно выбрать кнопкой или указать через `@username`; имя берётся из Telegram-профиля зарегистрированного участника.
5. Фотографии, место, календарная дата, приманка, судьба рыбы и заметка применяются ко всему улову. Повторная фотография определяется по Telegram `file_unique_id` и не сохраняется дважды.
6. На шаге геолокации участник может отправить новую точку или выбрать своё последнее именованное место; во втором случае координаты и название подставляются вместе.
7. Время поимки не хранится и не показывается. Дату можно выбрать кнопкой или ввести цифрами (`27.10.2026`) либо словами (`27 октября 2026 г.`).
8. Перед записью показывается общий предпросмотр; улов, фотографии и все рыбы сохраняются одной транзакцией.
9. После сохранения рыбы попадают в общую ленту, рекорды и статистику. Авторство рейтингов определяется настоящим рыбаком, а не участником, внёсшим запись.
10. Карточку каждой рыбы можно отправить в любой Telegram-чат через inline-режим.
11. Кнопка «✏️ Управлять» в карточке улова открывает редактор без SQL: можно изменить дату и место, а для каждой рыбы — вид, вес, длину и рыбака.

## Управление уловами

- Редактор открывается из общей ленты или по ссылке «Управлять уловом» из подробной карточки Mini App.
- Дата и место общие для всего улова. Вид, вес, длина и настоящий рыбак меняются отдельно для каждой рыбы.
- Из группового улова можно удалить одну рыбу. Если рыба была единственной, вместе с ней удаляется пустая сессия и её фотографии.
- Фотографии можно добавлять, удалять и назначать обложку. Дубли отсекаются по `file_unique_id`; последнюю фотографию удалить нельзя.
- Все удаления имеют отдельный экран подтверждения. Изменения сразу попадают в общую ленту, Mini App, рекорды и рейтинги.

## Рейтинги

- Общая статистика сравнивает рыбаков по числу уловов, суммарному весу, числу видов и рекордам.
- Кнопка «Статистика» по умолчанию открывает топ отдельных уловов всей компании по весу.
- Топ можно отфильтровать по виду рыбы или по имени рыбака.
- В каждом топе можно переключать сортировку между весом и длиной; записи без длины не участвуют в рейтинге по длине.
- Список видов строится динамически по рыбам, которые уже добавили участники.
- В лидерборде показываются место, результат, вид рыбы и рыбак — без даты и времени поимки.
- Активный фильтр отмечается галочкой. Нажатия подтверждаются до запросов к базе, поэтому холодный старт Neon не блокирует переключение; повторное нажатие активного фильтра безопасно.

## Бесплатная архитектура

```text
Telegram
   │ webhook
   ▼
Render Free Web Service ──────► Neon Free Postgres
   ▲          ▲                       ▲
   │          │ /health every 5 min   │ persistent data
   │      UptimeRobot Free            │
   │ deploy hook                      │
GitHub Actions ◄── GitHub repository
```

- Render запускает HTTP-сервис и принимает webhook Telegram.
- Render собирает TypeScript с явно установленными `devDependencies`, даже при `NODE_ENV=production`, а после сборки удаляет их из runtime-окружения.
- UptimeRobot проверяет `/health` раз в 5 минут и не даёт Render достичь 15 минут без входящего трафика.
- Render всё равно может перезапустить Free-сервис во время обслуживания, поэтому webhook и база рассчитаны на безопасный рестарт.
- Локальный диск Render временный, поэтому база находится в Neon Postgres.
- GitHub Actions проверяет типы, тесты и сборку, затем вызывает секретный Render Deploy Hook.

## Текущий продакшен

- Render Web Service: `https://fishner-bot.onrender.com`.
- Проверка доступности: `https://fishner-bot.onrender.com/health`.
- Первая успешная публикация выполнена 7 октября 2026 года.
- Деплой из GitHub Actions запускается только после успешных проверок через секрет `RENDER_DEPLOY_HOOK_URL`.
- UptimeRobot проверяет `/health` методом `HEAD` каждые 5 минут; endpoint также поддерживает обычный `GET` для ручной диагностики.

## Telegram Mini App

- Mini App открывается кнопкой «🌊 Открыть дневник» в личном чате с ботом и работает на том же Render Web Service по пути `/app`.
- Галерея показывает одну карточку на улов, даже если в нём несколько рыб и фотографий. Первая фотография служит обложкой, остальные открываются в карусели; рейтинги при этом считают каждую рыбу отдельно.
- Первый релиз включает общую галерею уловов, подробную карточку, интерактивную карту точек, календарь и визуальную сводку с рекордами.
- API принимает только свежие подписанные `Telegram.WebApp.initData`, затем дополнительно проверяет, что пользователь уже допущен в закрытый бот.
- Точные координаты и загрузка медиа доступны только после такой проверки. Значение `BOT_TOKEN` никогда не передаётся в браузер.
- Интерфейс мобильный, использует тему и безопасные зоны Telegram и не требует отдельной регистрации.
- Визуальный стиль — премиальный рыболовный клуб: единая фотографическая шапка с рассветом, тремя друзьями с удочками и вышитой эмблемой Fishner, тёплый бумажный фон, глубокая лесная зелень и золотые акценты. Главный экран использует сезонную клубную карточку, двухколоночные фотокарточки, общие достижения и тёмно-зелёную нижнюю навигацию; декор не должен мешать чтению данных.
- Из подробной карточки можно перейти в личный чат с `@fishner_bot` сразу к управлению выбранным уловом.

## Секреты

Ни одно значение из этого списка не должно попадать в Git:

- `BOT_TOKEN` — токен BotFather;
- `DATABASE_URL` — строка подключения Neon;
- `FRIEND_INVITE_CODE` — код приглашения;
- `WEBHOOK_SECRET` — секрет проверки webhook;
- `RENDER_DEPLOY_HOOK_URL` — секрет GitHub Actions.

## Этапы

### MVP

- приватное вступление;
- добавление улова;
- пакетное добавление нескольких рыб с 1–10 общих фотографий;
- отдельные роли автора записи и настоящего рыбака;
- общая лента;
- общие рекорды;
- рейтинг друзей и фильтруемые топы уловов;
- Telegram Mini App с галереей, картой, календарём и графиками;
- управление уловами без SQL;
- публикация карточек в чатах;
- Render + Neon + GitHub Actions + UptimeRobot.

### Следующий этап

- номинации и шуточные достижения.

### Последний этап

- именные рыбалки и совместные выезды.

### Не планируется

- полноценный режим работы бота в общем Telegram-чате. Inline-публикация карточек остаётся, но весь ввод и управление идут в личном чате с ботом.
